Playlists

"Show on all TVs" moves the shared pointer. It returns immediately and touches no TV; the screens follow within about five seconds.

Photos

Notes

Order. Photos are shown in filename order. Prefixing names with 01-, 02-, 03- is the only way to control the sequence.

Size. A TV browser has to download and decode every photo. Huge camera originals still work but a cold start can take many seconds per image; something around the screen's own resolution loads far better and looks identical.

Formats. JPEG, PNG, WebP, GIF and BMP. HEIC (the usual iPhone format) is refused, because no TV browser here can display it - export to JPEG first. A HEIC file renamed to .jpg is still detected and still refused.

Deleting a playlist is refused while it is the one the TVs are showing, or while any single TV is pinned to it. Switch away from it first.

Thumbnails are served from this server exactly as the TVs see them, so if an image is broken here it is broken there too.
