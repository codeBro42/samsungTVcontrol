1Server address

This is the address the TVs use to reach this server.

Get this right once. This exact string ends up inside the browser homepage that you type into every TV by hand. If the address changes later, every TV stops finding the slideshow and you have to walk round them all again.

So this machine needs a fixed address - a static IP, or a DHCP reservation for it - before you go any further.

    3Pair with each TV
    

      

        
One TV at a time, and you have to be standing at it. Turn the TV on, press Pair, then choose ALLOW in the box that appears on the TV screen. There are 90 seconds to do it.

        
Pairing only works from a machine on the same network as the TV - a set on another subnet refuses it instantly.

      

      

      

      
A stored token is not proof of pairing, so TVHub proves it: it nudges the volume up, reads the volume back off the TV, and puts it back. Only that counts as paired and verified.

JPEG, PNG, WebP, GIF and BMP. Photos straight off an iPhone are usually HEIC, which no TV browser can show - export or convert them to JPEG first.

      
Photos appear in filename order, so naming them 01-, 02-, 03- is the way to control the order. The full photo manager is on the Photos page.

    

  


  
  

    5Set each TV's homepage
    

      

        
This step cannot be automated. It is done by hand, once per TV, with the TV's own remote.

        
Many Samsung firmwares accept a "launch the browser at this address" command, reply that they did it, and then ignore the address. Every documented way of asking has been tried against these sets, including after a firmware update. So instead: each TV's browser homepage is set once, by hand, to the one address below.

        
Nothing after this is manual. Switching playlists changes what that one address serves, so the TVs never need to be touched again.
