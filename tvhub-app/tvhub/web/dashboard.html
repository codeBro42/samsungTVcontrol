TVHub __NAV__

Playlist

Switching a playlist only moves a pointer, so this returns instantly and touches no TV. Every screen that is showing the slideshow picks the change up within about five seconds, because the page asks the server what to show every five seconds.

Groups

A group action runs on its TVs in parallel and answers with one line per TV.

Screens

"Fix stuck TVs" only touches sets that are on but not showing the slideshow. It skips anything unpaired, off, or in standby, on the assumption that a TV which is off was turned off on purpose.

Identify puts a large number and the TV's short name on each screen, so you can walk the room and work out which TV is which. Every TV shares one page, so the number is chosen from the address that asked for it.

Activity

Controller URLs

Plain-text URLs for a controller (one line per TV, and always HTTP 200 when the route and the TV exist, so a controller never sees a comms error where it should see a message). Add /x/ in front of any of them to fire and forget.
