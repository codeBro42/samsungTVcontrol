Actions

"On" leaves standby - or, on a Frame, leaves Art Mode - then puts the slideshow back and sends one keypress so the page can go fullscreen. "Off" puts a Frame into Art Mode, which is what off means on a Frame: its reported power stays on in both states.

"Reopen browser" is how a page fix or a wedged browser is recovered without walking to the screen.

Remote

These are raw remote keys, sent straight through. The power key is a toggle, and on a Frame it toggles Art Mode instead of power - the Actions above are the safe way to change power.

A bare name is upper-cased and given a KEY_ prefix. *3 repeats a key three times; @500 waits 500 ms.

Setting a numeric volume needs the TV's UPnP port open; many models keep it closed, and those answer with an error suggesting the Vol +/- keys instead.

Macro recorder

A macro is dead reckoning: it presses keys and hopes the TV's home screen is where it was last time. Macros differ between model generations - the same room needed three presses of down on one generation of Frame and two on another - so each TV gets its own, and a firmware update that reshuffles the home screen means recording it again.

Turn Record on, then drive the TV with the pad above until its browser is open. Every key you press is both sent to the TV and added to the list.

    Replay sends the whole sequence through the server so the gap Tizen needs between keys is applied, and so the control port is re-checked first - a key sent the instant a TV leaves standby or Art Mode is silently dropped.

    Homepage

    -

    Set once by hand with the TV's remote: open Internet, go to this address, save it as the homepage. It never changes - switching playlists changes what it serves.

    Pairing

    
    
    Press Pair, then choose ALLOW on the TV screen. This only works from a machine on the TV's own network. Verify proves a stored token still works by nudging the volume and reading it back, and it also clears the mark on a Frame whose art channel hung once.
